# Mol-Bubi-project
Interactive web map that uses MOL Bubi bike-sharing demand and OpenStreetMap to rank Budapest’s busiest road segments without bike lanes and high-demand areas far from any station. Built with Streamlit, GeoPandas, OSMnx and H3. Slope-aware synthetic routes now, real GPS map-matching later. Exports the ranked GeoJSON/CSV results. Transparent scores.
